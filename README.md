# Lumira · Dil Kartları

6 dilde (Almanca, İngilizce, Arapça, Fransızca, İspanyolca, Rusça) kelime kartları,
quiz, seslendirme, liderlik tablosu ve kişisel ilerleme takibi. Arayüz 7 dile
(Türkçe, İngilizce, Almanca, Arapça, Fransızca, İspanyolca, Rusça) çevrilebilir.
Yüklenebilir, çevrimdışı çalışan bir uygulamadır.
- Sürüm: 2.0.
